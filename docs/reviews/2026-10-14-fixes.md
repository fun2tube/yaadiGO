## CTO review — correct and safe?

Found in review and **fixed before closing**:

| # | Finding | Sev | Fix |
|---|---|---|---|
| R1 | The board's "Advance paid" button set status `paid` — which every other module reads as **paid in full** — on a booking with nothing recorded, and sent it to ops as settled. | S1 | Money stages (part-paid, paid) are no longer manual; they follow the ledger. Board shows the real stage labels. |
| R2 | `recordPayment` on an unconfirmed seat request moved it to `part-paid` (a seat-holding stage) **without the trip lock** — an oversell path, and the new Record-payment screen would have exposed it. | S1 | Refused for manual payments ("confirm first"); a gateway payment is recorded but leaves the status for the desk to confirm under the lock. The payment link is refused for unconfirmed seat requests. |
| R3 | Merging a quote into a booking that already holds seats changed `travellers` — and seats are counted from `travellers` — so seats moved without the lock. | S1 | Seat count kept; the desk gets a note to adjust it on the board. Test added. |
| R4 | The Postgres `role` enum has no `accounts` — inviting an Accounts user would fail on the live database. | S1 | Migration `0005` adds it (with the invoice columns and `credit_notes`). **Not yet applied** — see below. |
| R5 | Gemini `abortSignal` was passed beside `config`, where the SDK ignores it: no Gemini call could ever be cancelled or timed out. The quote draft hung for 5 minutes when a model went silent. | S2 | Moved into `config`; each quote-draft attempt now has 45 s, the whole ladder 100 s, then a plain error. |
| R6 | The two "lite" models at the bottom of the fallback ladder reject `thinkingBudget: 0` (400) — those rungs had never worked. Measured. | S2 | The setting is left off for lite models. |
| R7 | Seat requests had no `salesOwnerId`, so scoping would have hidden them from their own salesperson. | S2 | Set from the lead's owner; older rows fall back to the lead's owner at read time. |
| R8 | A refund on a cancelled booking moved it back to part-paid. | S3 | Cancelled stays cancelled. |
| R9 | `/admin/bookings` had no permission check of its own. | S3 | `bookings.read` required. |
| R10 | "Today" buckets used the server's timezone — UTC on Vercel. | S3 | IST day boundaries on the server, calendar days in the label. |
